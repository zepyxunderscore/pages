Admin access required

Enter a GitHub Personal Access Token with repo scope to verify you're @xZepyx. The token will be used to push a verification entry to ${CONFIG.owner}/${CONFIG.authRepo}/auth. Stored in localStorage — never sent anywhere except GitHub API.

How to get a PAT
  1. Go to github.com/settings/tokens
  2. Click Generate new token → Fine-grained token
  3. Set Repository access to Public Repositories (read-only) and add ${CONFIG.owner}/${CONFIG.authRepo} with Read and Write access to Contents
  4. Generate and paste the token above
  5. It will push to ${CONFIG.owner}/${CONFIG.authRepo}/auth to verify write access
